这是一套 Spring 源码笔记（基于 Spring 5.3.13），记录 Spring / SpringMVC / SpringBoot 的核心机制。目的很朴素：写业务代码时，知道框架在背后干了什么——出了问题能顺着源码找到根因。

> 阅读建议：按下面的顺序看，后一篇依赖前一篇。每篇都尽量"跟着源码走一遍"，而不是背结论。XML 形式基本略过（那是上一个时代的写法），主线以 SpringBoot 的启动流程和注解为准。
